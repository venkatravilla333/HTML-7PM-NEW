


What is HTML
------------

HTML stands for Hypertext Markup Language, which is used to structure content on the web page. HTML uses tags to structure content on the web.



Basic tags
==========

<!DOCTYPE>: Specifies the document type and version of HTML being used.

<html>: The root element that contains all other HTML elements on the page.

<head>: Contains metadata about the document, such as the title, and stylesheet link or scripts and              meta tags.

<title>: Defines the title of the webpage, which appears in the browser tab.

<meta>: Provides metadata about document.

<link>: Links external stylesheets and icons.

<script>: Embeds external JavaScript file.

<style>: Defines CSS for styling html content.

<body>: Contains the main content of the webpage, including text, images, audio, video and 
        other elements.


html tags vs html elements vs html attributes. 
----------------------------------------------

Tag → just the <p> </p>

Element → complete structure (tag + content) <p>This is para</p>

Attribute → It is the property of html, It gives extra info about tag to browser. It is in opening tag.


HTML Attributes
---------------

Html attributes are the properties of html element and it is used to give extra information about element to the browser. Every attribute will be in the key value pair.


Block-level & Inline elements & Inline block
--------------------------------------------


-Block level element 

- Takes the full width (100%) of parent.
- Takes only required height for content.
- Every block level element starts in a new line.
- We can give custom width and height.


-Inline element 

- Takes only required width for content.
- Takes only required height for content.
- Every inline element starts in same line (They appear side by side)
- We can not give custom width and height.

-Inline-block element 

- Takes only required width for content.
- Takes only required height for content.
- Every inline element starts in same line (They appear side by side)
- We can give custom width and height.

3) image element
================

<img src='' width='' height='' alt='' title=''/>


 - The <img> tag is used to display images on a web page.
 - Self-closing.
 - Inline block element.

Attributes: src, alt, width, height, title

✅ Product images, banners, logos.

✅ <img src="iphone16.jpg" alt="iPhone 16 Pro" width="400" loading="lazy" />

1️. alt attribute

Used to describe what the image is.

Helps search engines and blind users understand the image.

Example:

<img src="iphone16.jpg" alt="iPhone 16 Pro smartphone" />


=> “If image doesn’t load, browser shows alt text.”

2️. loading="lazy"

Means don’t load the image until user scrolls near it.

Makes pages open faster, saves data, and improves performance.

Example:

<img src="iphone16.jpg" alt="iPhone 16 Pro" loading="lazy" />


=> “Used in product listings where many images exist.”

3️. srcset

Used to load different image sizes on different devices.

Helps mobile users download smaller images, saves bandwidth.

Example:

<img
  src="iphone16-400.jpg"
  srcset="iphone16-400.jpg 400w, iphone16-800.jpg 800w"
  sizes="(max-width:600px) 100vw, 400px"
  alt="iPhone 16 Pro"
  loading="lazy"
/>


=> “Browser automatically chooses the right image size.”

5) Anchor element
=================

  <a href='' target=''>content </a>

  - The <a> tag (anchor tag) is used to create a links in the webpage. 
  - By using links we can create
               1) Inter navigation (navigation between documents) 
               2) Intra navigation (navigation between sections with in document)

   Atttribute:
   ----------
   href = 'path of another webpage' or '#id value of section in same page'  
   target => Specifies where to open the linked document.

	        _blank 
                _self (default)	

   _blank    => Opens the linked document in a new window or tab.
   _self     => Open the link in the current frame.(default)


✅ Real-time eCommerce Use Cases

1. Navigation Links

   Linking to Home, Products, Cart, Orders, Profile pages.

2. Footer Links

   External links to Privacy Policy, Terms & Conditions, Social Media pages.

   Redirect users to partner sites, e.g., manufacturer’s product manual.

6. React / SPA Case

   In React apps, <a> is often replaced with <Link> from react-router-dom to avoid full page               reloads.

8) List elements
=================


<ul> → unordered (bulleted) list
<ol> → ordered (numbered) list
<li> → list item

<dt> → data term
<dd> → data definition


By default:

 - <ul> → display: block
 - <ol> → display: block
 - <dl> → display: block



 - Unordered List <ul> → Order does NOT matter. (Features, categories, menu items)

Attributes

For `<ol>` (Ordered List)

 - start → start number/letter from a specific value
 - reversed → reverse the numbering

 For <ul> (Unordered List)

 - type → disc (default), circle, square, none

12) Table elements
==================

 - Basic Table Elements

* <table> → Defines a table
* <caption> → Title/caption for the table
* <thead> → Groups header content
* <tbody> → Groups body content
* <tfoot> → Groups footer content
* <tr> → Table row
* <th> → Table header cell (bold + centered by default)
* <td> → Table data cell


Attributes (Legacy HTML)

1. Borders & Rules

   * border="1|5|10" → thickness of border
   * frame → border position (box, above, below, rhs, lhs etc.)
   * rules → where to apply borders (rows, cols, groups, all)

2. Width & Height

   * width → applies to full table including head/body/footer
   * height → applies to body but not <thead> or <tfoot>

3. Cell Spacing & Padding

   * cellspacing → space between cells
   * cellpadding → space inside cells

4. Merging Cells

   * colspan → merge columns in a row
   * rowspan → merge rows in a column

5. Alignment

   * text-align (align) → horizontal alignment (left, center, right)
   * vertical-align (valign) → vertical alignment (top, middle, bottom)

6. Background

   * bgcolor → background color

 Note: Most of these attributes (align, valign, bgcolor, cellspacing, cellpadding) are deprecated in         HTML5. Use CSS instead.

Example:

th, td {
  text-align: center; 
  vertical-align: middle;
  padding: 10px; 
  border: 1px solid black;
}

13) Form element
================

Form element is used to take input from an user to send data to server and then db.
The <form> element is a container for different types of input elements, such as: text fields, checkboxes, radio buttons, submit buttons, etc.

Form Elemenets:
---------------

The HTML <form> element can contain one or more of the following form elements.

  <form>	=> Defines an HTML form for user input.
  <input>	=> <input> element can be displayed in many ways, depending on the type attribute.
  <label>	=> Defines a label for an <input> element.
                   The for attribute of the <label> tag should be equal to the id attribute of the                          <input> element to bind them together.
  <textarea>	=> Defines a multiline input control (text area).
                   The <textarea> element is often used in a form, to collect user inputs like                              comments or reviews.
                   The size of a text area is specified by the cols and rows attributes.
  <button>	=> Defines a clickable button.

  <fieldset>	=> Groups related elements in a form.
  <legend>	=> Defines a caption for a <fieldset> element.

  <select>	=> Defines a drop-down list.
  <option>	=> Defines an option in a drop-down list.(The <option> tags inside <select>                                 element define the available options in the drop-down list).(selected attribute)
  <optgroup>	=> Defines a group of related options in a drop-down list.

  <datalist>	=> Specifies a list of pre-defined options for input controls.

-The <datalist> tag is used to provide an "autocomplete" feature for <input> elements. Users will see a drop-down list of pre-defined options as they input data.

-The <datalist> element's id attribute must be equal to the <input> element's list attribute (this   binds them together).

The <select> element defines a drop-down list:

The <option> element defines an option that can be selected.

By default, the first item in the drop-down list is selected.

To define a pre-selected option, add the selected attribute to the option:

Use the multiple attribute to allow the user to select more than one value:

Use the size attribute to specify the number of visible values:
  

Form attributes:
----------------

-autocomplete: 'on' (in form opening tag).
-novalidate => form-data (input) should not be validated when submitted.
-onSubmit: form data will be submited when click on submit button.


Input element Attributes
------------------------

  Input element attributes
  ------------------------
  1.type: text | password | email | button | radio | checkbox | number | color | date | reset | submit |           tel | range | time | month
 
    The type attribute is used to specify the type of the input element. Its default value is text.

  2.placeholder: Placeholder attribute is used to specify hint that describes the expected value                          of an input field.
  3.value:       The value attribute is used to specify the value of the input element.
  4.name:        The name attribute is used to specify the name of the input element.
  5.maxlength:   This property is used to specifies the maximum number of characters allowed in an                        <input> element
  6.size:        This property is used to specifies the width of <input> element(default 20 chars)
  
  7.required:    The required attribute specifies that an input field must be filled out before                           submitting the form.
  8.disabled:    The disabled attribute specifies that the element should be disabled. The                                disabled attribute can be set to keep a user from using the < input > element until                      some other condition has been fulfilled.
  9.readonly:    The readonly attribute specifies that an input field is read-only. A read-only input                     field cannot be modified. A form will still submit an input field that is readonly, but                  will not submit an input field that is disabled.

Note:
-----

- The default width of an input field is 20 characters.
- The "for" attribute of the <label> tag should be equal to the "id" attribute of the <input> element to    bind them together.
- Name attribute should be same value for all radio buttons to select any one of them.
- The <input type="submit"> defines button for submitting the form data to form-handler(function).


<select>
========

It creates a drop-down list of fixed options.

The user can only choose from the options provided (cannot type a new value unless you hack with JavaScript).

Mostly used when you want to restrict the input to certain values.


<label for="country">Choose a country:</label>

  <option value="usa">USA</option>

</select>


🔹 Here the user must pick India, USA, or UK — nothing else.

✅ <datalist>
=============

It creates a list of suggestions for an <input> field.

The user can choose from suggestions OR type their own value.

Good when you want to guide the user but also allow flexibility.

<label for="browser">Choose a browser:</label>
<input list="browsers" id="browser" name="browser">

<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
  <option value="Edge">
</datalist>


🔹 Here the user can pick from Chrome, Firefox, Safari, Edge…
But they can also type "Opera" or any browser not listed.

16) Formatting Elements
=======================

Formatting elements were designed to display special types of text with css styles:

  Bold text: <b> or <strong>
  --------------------------

  HTML5 provides two tags to make text bold: <b> and <strong>.
  Both tags have the same effect of making the enclosed text bold, but <strong> is preferred because it    indicates that the text is important for semantic purposes.

  Italicized text: <i> or <em>
  ----------------------------

  HTML5 provides two tags to make text italic: <i> and <em>. Both tags have the same effect of making      the enclosed text italic, but <em> is preferred because it indicates that the text has emphasis for      semantic purposes.

  Strike-through text: <del> or <s>
  ---------------------------------

  HTML5 provides two tags to make text strike-through: <s> and <del>. Both tags have the same effect of    making the enclosed text strike-through, but <del> is preferred because it indicates that the text has   been deleted for semantic purposes.

  Superscript and subscript text: <sup> or <sub>
  ----------------------------------------------

  HTML5 provides two tags to make text superscript and subscript: <sup> and <sub>, respectively.

  u and ins
  ---------
  HTML5 provides two tags u and ins. Both tags have the same effect of making underline.
  <ins> is used for semantic purpose. The <ins> tags means content inserted after it was first             published. The <u> tag is simply for underlining and has no meaning.

  small vs big
  ------------
  In HTML, the <small> tag is used to emphasize small text or information that is of secondary             significance, such as copyright and legal disclaimer.
  The <small> tag can be used to mark up a copyright notice or license agreement.
  HTML <big> tag was used to increase the text font size one level bigger than the document's base font    size.

20) Web storage (HTML-5)
========================

* Two types:

  * localStorage → No expiration, persistent.
  * sessionStorage → Exists until browser/tab closes.
  * Used to store client-side data (5MB+).
  * More secure than cookies since data isn’t sent to the server automatically.

✅ Real-time eCommerce Use Cases

1. Cart Persistence

   * Save cart items in localStorage so they stay even if page reloads.

2. Checkout Progress

   * Use sessionStorage to save temporary checkout step info.

3. Search History / Recently Viewed Products

   * Store user’s last searched products in `localStorage`.

4. Personalization

   * Store user preferences like theme, currency, or language.

✅ Interview Explanation

"I implemented persistent carts using `localStorage`. When a user adds items to the cart without logging in, the cart remains even after refresh. Once logged in, I synced this data with the backend. For sensitive data like payment info, I avoided localStorage and used sessionStorage only for temporary session-related details."

💻 Code Examples

1. Store & Retrieve Cart Items

<script>
// Store cart items
localStorage.setItem("cart", JSON.stringify(["iPhone 16 Pro", "Nike Shoes"]));

// Retrieve cart items
let cart = JSON.parse(localStorage.getItem("cart"));
console.log("Cart:", cart);
</script>


2. Remove Items

<script>
localStorage.removeItem("cart"); // removes cart only
// OR
localStorage.clear(); // clears all localStorage data
</script>


3. Using Session Storage for Checkout**

<script>
// Save checkout step temporarily

sessionStorage.setItem("step", "address");

// Retrieve step

let step = sessionStorage.getItem("step");
console.log("Current Step:", step);

// Remove session data

sessionStorage.removeItem("step");
</script>


# ✅ Student Takeaway

* Meta tags → SEO, responsiveness, multilingual support, auto-refresh for dashboards.
* Web Storage → Persistent carts (localStorage), temporary session data (sessionStorage).
* Interview Tip → Always mention syncing localStorage with DB for persistence & avoiding sensitive data   in localStorage for security reasons.

# 🎯 20 HTML Interview Q&A for eCommerce Projects


1) Headings (`<h1> - <h6>`)

Q: Why is `<h1>` important in an eCommerce product page?

A: `<h1>` is used for the main product title. It improves SEO so search engines recognize the product    name. For example, "iPhone 16 Pro" is always in `<h1>`.

2) Paragraph (`<p>`)

Q: Where did you use `<p>` in your project?

A:For product descriptions, terms & conditions, and return policies. I avoided `<br>` for spacing and   used CSS margins.

3) Image (`<img>`)

Q: How do you optimize product images?

A: I used the `alt` attribute for SEO, `loading="lazy"` for performance, and `srcset` for responsive images.


4) Button (`<button>`)

Q: Difference between `type="button"` and `type="submit"` in eCommerce forms?
A: `type="button"` triggers JS functions like "Add to Cart", while `type="submit"` is used in forms like    "Checkout".

5) Anchor (`<a>`)

Q: How did you use `<a>` for navigation?

A: I used `<a>` for external links (policies, social media). For internal routing like `/cart`, we used React Router’s `<Link>`.


6) Division (`<div>`)

Q: What’s the role of `<div>` in product pages?

A: `<div>` grouped product details (image, name, price, button). Combined with Flexbox/Grid, it created    responsive layouts.


7) Span (`<span>`)

Q: Why use `<span>` instead of `<div>`?

A: `<span>` is inline. I used it for inline content like discount labels ("50% OFF") or price    formatting.


8) `<br>`

Q: Did you use `<br>` often?

A: Rarely. Only in formatted addresses (checkout forms). For spacing, I always used CSS.


9) `<hr>`

Q: How did you use `<hr>` in your store?

A: To visually separate sections, like product description and customer reviews, styled with CSS for    consistency.


10) Lists (`<ul>, <ol>, <dl>`)

Q: Give an example of lists in your project.

A: `<ul>` for product features (bullet points), `<ol>` for checkout steps, `<dl>` for FAQs.


11) HTML Entities

Q: Which entities did you use in eCommerce?

A: `&copy;` for footer copyright, `&reg;` for brand names, and `&nbsp;` for preventing line breaks in prices.


12) Tables (`<table>`)

Q: Where did you use `<table>` in your project?

A: In the admin dashboard for order history and sales reports. Each row showed order ID, product, price,    and status.


13) Forms (`<form>`)

Q: How did you use forms in checkout?

A: For login, registration, shipping address, and payment. I used `required` for validation and    `<label>` for accessibility.


14) Marquee (`<marquee>`)

Q: Did you use `<marquee>` in your project?
A: Only for demo purposes. Since it’s deprecated, I replaced it with CSS animations for scrolling    offers.


15) Media (`<audio>, <video>`)

Q: Where did you use `<video>` in eCommerce?

A: For product demo videos, unboxing clips, and customer testimonial videos.


16) Formatting Elements

Q: How do you show discounts with formatting tags?

A: I used `<del>` for old price, `<strong>` for new price, and `<mark>` for highlighting offers.


17) Semantic Elements (`<header>, <nav>, <footer>`)

Q: Why use semantic elements instead of `<div>`?

A: Semantic elements improve SEO and readability. Example: `<article>` for product cards, `<footer>` for    policies.


18) Iframe (`<iframe>`)

Q: How did you use `<iframe>` securely?

A: For payment gateways (Razorpay, PayPal) and embedding YouTube videos. I used `sandbox` and    `frameborder=0` for security.


19) Meta tags (`<meta>`)

Q: Which meta tags are critical for eCommerce SEO?

A: `description` for product SEO, `viewport` for responsive design, and `charset="UTF-8"` for special    characters.


20) Web Storage (`localStorage, sessionStorage`)

Q: How did you use localStorage in your project?

A: To persist cart items across refreshes. On login, I synced localStorage cart with the backend       database.
